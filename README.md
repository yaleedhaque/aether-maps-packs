# aether-maps-packs

Anonymous download distribution for the **AetherCompass** app's optional *Aether Maps* plugin.
The AetherCompass source repo stays private; only these runtime assets are public.

Assets are attached to the [`maps-packs` release](https://github.com/yaleedhaque/aether-maps-packs/releases/tag/maps-packs):

| Asset | What it is |
|---|---|
| `world-z7.pmtiles` | World overview basemap (z0–7) |
| `<division>-z15.pmtiles` | Bangladesh division basemaps (z0–15) |
| `gh-bd.tgz` | GraphHopper routing graph for Bangladesh (car+bike CH) |
| `maps-release.apk` | The Aether Maps plugin APK |

Do not delete or rename assets — the installed app hardcodes these URLs.
